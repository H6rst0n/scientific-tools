歡迎使用 **科學與實用腳本工具箱**！這是一個專為科研人員、工程師與學生打造的輕量化在線工具平台。

所有工具皆採用 **純前端技術（Client-side）** 開發，無需安裝任何環境或依賴套件，打開瀏覽器即可直接使用。

🌐 **線上使用入口**：[點此立即前往工具箱首頁](https://H6rst0n.github.io/scientific-tools/) 

---

## 🌟 核心特色

- ⚡ **隨開即用**：零安裝、零設定，支援現代主流瀏覽器（Chrome, Edge, Firefox, Safari）。
- 🔒 **100% 隱私與安全**：所有數據計算、繪圖渲染與檔案匯出均在使用者本地端（瀏覽器記憶體）完成，數據**絕不上傳**任何雲端伺服器。
- 💾 **自動儲存與進度還原**：利用本地儲存技術（`localStorage`），關閉分頁後下次開啟自動載入上次編輯進度。
- 📱 **響應式現代化介面**：支援直覺的卡片式導航、即時關鍵字搜尋與分類篩選。

---

## 🛠️ 工具清單

### 1. ⚛️ 科研能量圖繪製工具 (Reaction Energy Profile Plotter)
- **簡介**：專為化學、物理與材料計算化學設計的反應位能面（PES / Reaction Coordinate Diagram）繪製工具。
- **主要功能**：
  - 支援多反應路徑（Multi-pathway）對比。
  - D3.js 互動式節點能階拖曳、標籤直接編輯與即時預覽。
  - 靈活自訂畫布比例（16:9, 4:3, 1:1, 自訂像素）與色盤。
  - 支援高解析度出版級格式匯出（SVG 向量圖、300+ DPI PNG、PDF 與 JSON 專案檔）。
- **工具路徑**：[`energy-profile-plotter.html`](./energy-profile-plotter.html)

## 💻 離線與本機使用

如果您需要在無網路環境下使用：

1. 點擊右上角 `Code` -> `Download ZIP` 下載整個專案解壓縮。
2. 直接雙擊 `index.html` 或各工具的 `.html` 檔案即可在瀏覽器中完全離線運行。
